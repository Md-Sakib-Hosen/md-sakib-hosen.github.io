## Local Preview

Since this is a static site with no build step required, you can preview it locally with any HTTP server:

```bash
git clone https://github.com/Md-Sakib-Hosen/md-sakib-hosen.github.io.git
cd md-sakib-hosen.github.io
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
