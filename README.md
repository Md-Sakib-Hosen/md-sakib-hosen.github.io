# MD Sakib Hosen - Professional Portfolio

This repository contains the production code for MD Sakib Hosen's live portfolio website.

## What's Included:
- `index.html`: Fully self-contained, high-performance portfolio featuring embedded high-resolution photography, interactive filtering, case study modals, and certified credentials.
- `MD_Sakib_Hosen_CV.pdf`: Official graphical CV with direct download integration.
- `images/`: Local backup photography assets.
- `push_to_git.sh` / `push_to_git.bat`: One-click scripts to sync all files directly to your GitHub repository.

## How to Deploy to GitHub Pages:
1. Extract all files into your repository folder.
2. Run `push_to_git.bat` (Windows) or `./push_to_git.sh` (Mac/Linux).
3. If deploying manually, ensure you run:
   ```bash
   git add -A
   git commit -m "Fix images and update portfolio"
   git push origin main
   ```
